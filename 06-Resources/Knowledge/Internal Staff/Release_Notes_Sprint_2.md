TransUnion Cleanroom Analytics

CA 03-01 | Project Creation: Conditional 2 or 3-party Project

Data Buyer clients can create cleanroom projects that securely match their customer dataset against TransUnion bureau data. Projects can run as 2-party (Client + TU) or 3-party (Client + TU + Partner) — the client chooses during setup by optionally adding a shared partner dataset. Matching uses multiple encrypted identifiers (ID number, phone, email) and no raw personal data is shared between parties.

- User Story: https://app.clickup.com/9012824942/v/dc/8ck9jve-90952

CA-03d | PowerBI Data Model & Report Template Creation for a 3-Party Project (BI Viz Phase 2)

BI report template for 3-party TU cleanroom projects. Provides visual insights into matched data across all three datasets.
