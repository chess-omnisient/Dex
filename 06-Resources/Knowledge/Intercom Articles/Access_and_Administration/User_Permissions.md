# Assigning User Permissions During Project Creation

User access is configured during the first step of the project creation wizard. You can add users from your organisation and assign their roles before the project is submitted.

---

## Roles

| Role | Can do |
|---|---|
| **Owner** | Full control — manage users, edit content, update permissions, delete project |
| **Read and Write** | View and edit the project, manage data and reports, perform selections |
| **Read Only** | View only — cannot edit the project, data, or reports |

You are automatically set as **Owner** when you create a project. All added users default to **Read Only**.

---

## Before you start

- You must be creating a new project — permissions can also be updated after creation if you are the Owner
- Only users from your organisation appear in search results

---

## Steps

1. Open the project creation wizard via the **+** icon in the side navigation or **Create Project** on the Projects screen.
2. Select your project template.
3. In step 1 of the wizard, locate the **User Access and Permissions** section.
4. Use the search bar to find users by name or email address.
5. Select a user to add them to the project. Added users will no longer appear in search results.
6. Use the role dropdown next to each user's name to assign their role.
7. To remove a user before completing setup, click the delete icon next to their name.

> You cannot remove yourself from a project or change your own role during setup.

---

## Notes

- Assign Owner permissions carefully — only grant full control where necessary
- Default all added users to Read Only and escalate only when required
- Review the user list before submitting the project
