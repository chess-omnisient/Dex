# Bank Overlap Report Walkthrough – Standard Operating Procedure

## 1. Introduction

## 2. Step-by-Step Guide: Opening and Reviewing the Overlap Report

### Step 1 – Log in
- Log in to the Omnisient demo platform with the **bobby** login details
- In the top right corner, confirm you're logged into the bank (**Banco Boitata**)

### Step 2 – Open the Overlap project
- Go to **Project Workspace** > **Projects Dashboard**
- Click the first Overlap project (the bank overlap project)

### Step 3 – Review Project Tables
- Open **Project Tables** to see the tables used to build this Overlap project

### Step 4 – Open the Power BI report
- The Power BI report view is straightforward at this stage – no extra steps needed here

### Step 5 – Open with Jupyter Notebook
- Choose the **Large** workspace
- Click **Confirm**
- Jupyter spins up in the background

### Step 6 – Trust the report file
- Only one file is available at this point: the bank overlap report
- Click **Trust HTML** – this loads all the data into the notebook

### Step 7 – Review and present the report
- Scroll through the report and walk through the different reporting items
- Use the reference table on the left as a guide while presenting
- This is the version to demo to potential clients

## 3. Standard Operating Procedure

**When running this for a client demo:**
1. Confirm you're logged in on the bank (Banco Boitata) side
2. Open the Overlap project > Jupyter Notebook > Large workspace > Trust HTML
3. Walk the client through the reporting items using the left-hand reference table

**Escalation:**
- If Jupyter fails to spin up or the report won't load after clicking Trust HTML, flag [[Donovan]] or Support (same escalation path as the main Febraban SOP)

**What NOT to worry about:**
- Sourcing extra material yourself – [[Donovan]] has additional documents he can share if a client asks for more depth
