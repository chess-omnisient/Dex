# RCA Template

Required for any Sev 1, 2 or 3 issue impacting clients. The engineer who resolved the issue writes it; the account manager shares it with the affected client once the root cause is identified and remediation requirements are clear. See [[Support and Incident Process]] section 4.

Copy everything below the line into a new file named `RCA <short description> (ClickUp <ticket id>).md`.
