Where to find Reports

In the Omnisient Platform, go to Datasets → Reports.

Reports types

Omnisient builds each report using your data, then makes it available under Reports.

Report Type

Description

API report

A report covering activity and performance for an API integration on your data.

QA report

A report covering data quality checks run against your data, such as completeness, error rates, or anomalies.

Batch report

A report covering a bulk upload: records received, records matched and enriched with metadata, and file upload details.

Custom report

A report built for a specific need.

Access

Omnisient sets access as view-only or edit on a per-report basis, based on the report type and the sensitivity of the underlying data.

Access level

What it means

View-only

You can view and filter the report.

Edit

You can view the report and create your own visuals.
