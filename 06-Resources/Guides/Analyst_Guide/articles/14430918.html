Analytics Studio is a standalone desktop application for running SQL and Jupyter Notebook sessions. It replaces the in-app experience, allowing multiple sessions to run concurrently. Analytics Studio is available on Windows only.

Things to know

  • Analytics Studio does not have its own interface for browsing or selecting data. It relies on the platform to pass session context, so it must always be launched from one of the entry points below.

  • Users who are unable to install desktop applications due to company security policies can continue using SQL Pad and Jupyter Notebook embedded in the web app.

How to open Analytics Studio

From Own Data Preparation

Navigate to Datasets → Own Data Preparation or Project Workspace → Own Data Preparation. Click either the SQLPad or Jupyter Notebook widget to launch Analytics Studio. This opens a session with access to all your datasets.

From a project

Navigate to a project and locate the Project Table widget. Click Open with and select SQLPad or Jupyter Notebook from the dropdown. This opens a session in the context of that project, with access to the datasets linked to it.

Installing Analytics Studio

When launching Analytics Studio for the first time from any entry point, the platform will check whether the application is installed on your machine.

  • If not installed: A modal will appear with a download button. Click Download to download the installer (.exe), then run it to complete installation.

  • If already installed: Analytics Studio will open automatically.

Once the application opens, you will be prompted to sign in using the same credentials you use to access the platform.

Session limits

Session type

Maximum concurrent sessions

SQL Pad

2

Jupyter Notebook

2

All four sessions can be open at the same time, regardless of which entry point was used to launch them.

If you attempt to open more than the allowed number of sessions, a modal will appear: "You have exceeded the number of instances allowed."

Closing a session frees up the slot, but resources take approximately one minute to release. You may need to wait briefly before opening a new session.

Copy/paste behaviour

Copy/paste restrictions vary by tool within Analytics Studio:

Tool

Copy/paste

SQLPad

Valid, complete SQL statements can be copied freely. Non-SQL content is restricted. Blocks containing more than 10 consecutive lines of SQL comments are also restricted.

Jupyter Notebook

Valid, complete Python statements can be copied freely. Non-Python content is restricted.
