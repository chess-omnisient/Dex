Tables throughout the Omnisient Platform share a common set of controls for filtering, sorting, paging, and customizing what you see.

Key Capabilities

Across most tables, you can:

  • Filter and search using the Filters panel, and save filter combinations as reusable views

  • Sort by any column by clicking its header

  • Page through results, with a configurable number of rows per page

  • Show, hide, and reorder columns to fit what you see

  • Resize columns by dragging the boundary between headers

Not every table exposes every control. What's available depends on the columns and data in that specific table.

Filtering and Searching

Click the Filters button above a table to open the filtering panel. Clicking it again closes the panel.

What you can filter on depends on the columns available in that table. Common filters include:

  • Status (e.g. Active, Processing, Locked)

  • Type

  • Date

The search bar is always accessible in the filters panel.

Applied filters

When one or more filters are applied, the Filters button turns blue and shows a counter badge with the number of active filters. This gives you an at-a-glance signal that the table is showing filtered results.

Use Clear Filters button or the cross on the Filter Button to remove all applied filters at once and return to the unfiltered table.

Saving filters as a view

If you find yourself applying the same filters repeatedly, save them as a view:

  1. Apply the filters you want.

  2. Click Save As.

  3. Enter a view name and click Save.

Saved views appear as tabs in the filter bar alongside All, and persist across sessions, refreshes, and logins.

You can also start a new view directly: click + Add View, which opens the filters panel and prompts you to apply filters and save.

Editing or deleting a view

Open the filters panel while a saved view is active, then click the context menu next to the view. From there you can Edit Name or Delete View.

Sorting

Click a column heading to sort the table by that column. Clicking the same heading again reverses the sort direction; clicking a third time returns to the table's default sort.

An arrow on the column heading shows whether (and how) a column is currently sorted:

  • Arrow present: the table is sorted by that column, in the direction shown.

  • No arrow on any column: the table is showing its default sort.

Most tables load with a sensible default sort (for example, most recently created or updated first) rather than arbitrary order. A table can only sort one column at a time.

Paging

Tables show a limited number of rows per page, with controls to move between pages and to change how many rows are shown at once (e.g. 10/25/50/100 rows per page).

⚠️ Sorting and paging are not saved in views and do not persist across sessions or refreshes. Only filter criteria are saved in a view. Each time you open a table, it loads with its default sort until you re-sort manually and tables reopen on the first page at the default page size each time.

Column Customization

Click the gear icon above a table to open the column customization panel. Here you can show, hide, and reorder columns to match how you work.

  • Show/hide: toggle the eye icon next to a column name. Columns with a lock icon instead of an eye icon cannot be hidden - they're required for the table to make sense (e.g. the Name column).

  • Reorder: drag columns into the order you prefer using the handle beside each row.

  • Reset: click Reset to return all columns to their original visibility and order.

  • Save: click Save Setup to persist your changes.

💡 If you're looking for a specific piece of information and can't find it in a table, check column customization first - the column you need may simply be hidden. Some columns are hidden by default.

Column Resizing

Hover over the boundary between two column headers and drag to resize a column to your preferred width. Column widths persist across refreshes and sessions.

Columns Missing?

If a column you expect to see isn't visible and isn't hidden in column customization:

  1. Check whether other columns have been dragged wider than needed, pushing it out of view.

  2. Check for a horizontal scrollbar at the bottom of the table - the column may simply be scrolled out of view.

  3. If the column still can't be found, contact support or log a feature request.

Viewing more information

A dotted underline beneath a piece of text is a general signal for "this is clickable" - you'll see it on names, links, and other in-table values wherever clicking them does something. In tables, it tells you a row (or a specific value in the row) can be interacted with.

  • Eye icon present on hover: clicking the link opens the full detail view. The eye icon at the end of the row is the primary signal that a full detail view is available.

  • No eye icon on hover: clicking the underlined text instead opens a lighter-weight popup or bottom sheet with additional information.
