Available datasets are datasets that have completed processing and have been successfully registered in the platform. Once registered, datasets are ready to be used in projects and can also be shared with approved connection partners..

Available datasets represent a stable, project-ready version of your data. They support ongoing use cases such as collaboration and project creation.

Key Capabilities

Available datasets allow you to:

  • Use datasets directly in projects

  • Share datasets with connection partners

  • Map and configure fields to ensure project compatibility

  • Upload new versions of a dataset while maintaining historical tracking

The Available Datasets table gives you an at-a-glance view of every registered dataset available in an organization, with columns such as Name, Description, Type, Code, Create Date, Status and Uploads.

Each dataset has a single Status that reflects the overall state of the dataset. This is separate from the per-upload status shown in the Uploads column, covered below.

Name

Description

Processing

Dataset is ready to be shared or used in a project

Marked for Delete

The dataset has been flagged for deletion, it will be deleted during the next deletion cycle

Uploads

The Uploads column gives you a quick read on how many of a dataset's uploads are ready and flags any that need attention. It sits alongside the dataset's own Status: Status describes the dataset as a whole, while Uploads summarizes the individual uploads that make it up.

The ready / total fraction

Each row shows a fraction such as `2/3`, meaning the dataset has three uploads, two of which are Ready. The numerator counts uploads currently in Ready status; the denominator counts all non-deleted uploads. The fraction updates as uploads finish processing or are removed.

The attention icon

An icon beside the fraction takes the color of the most serious issue across the dataset's uploads, so you can triage by color alone:

Color

When it appears

Green

All uploads are ready

Amber

When the latest dataset(s) are uploading

Red

At least one uploads needs attention (PII Leak detected or High Error Rates present on the dataset) or the upload has failed.

When hovering on the icon a tooltip shows the state in plain words, for example "4 of 5 uploads ready . 1 requires review", so you don't have to interpret the color.

Clicking on the fraction opens a detail view where you can review each upload and take action.

💡Derived datasets are created inside the platform rather than from uploads, so their Uploads cell stays empty.

Deleting a Dataset

It's worth periodically clearing out datasets you no longer use, deleting old or unused datasets keeps your workspace organized and easier to navigate.

You can start a deletion from either of two places: the row's context menu (three dots) on the Available Datasets table, or the context menu within the dataset's own Detail View. Both open the same Delete dataset modal.

In the Delete dataset modal: the Deletion date field defaults to today's date, but you can push it out using the date picker if you'd rather schedule the deletion for later. If you want a safety net in case this turns out to be a mistake, tick Backup first, this takes a backup you can have restored by contacting support. Once you're ready, click Delete to confirm.

⏱️ The dataset is only deleted at the end of day, and it can take up to 24 hours for the data to be fully removed.

When deletion is blocked: if the dataset is currently shared with a connection partner or linked to one or more active projects, a modal appears instead, listing the impacted dataset shares and projects. Deactivate the dataset shares and delete the linked project(s) first. The View Projects and View Dataset Shares jump straight to the relevant screens to do this.

Updating the Customer Identifier and Other Registration Details

Select Update from the context menu (three dots) on the table row or in the Detail View to edit a dataset's Friendly Name, Description, or Customer Identifier. You'll be asked to confirm first, since the dataset will briefly reprocess and become unavailable.

⚠️ Changing the Customer Identifier means existing selections, projects, and dataset shares built on the old identifier will need to be recreated.

See Retry with a Different Customer Identifier for the full walkthrough.

Available Dataset Detail View

The Available Dataset Detail View provides a complete overview of the dataset, including metadata, project usage, collaboration settings, upload history, and lineage information.

1. Editable Dataset Settings

Within the detail view, you can update the following dataset attributes:

  • Edit Dataset Display Name

  • Change Dataset Type

  • Add or update Dataset Description

2. Dataset Summary

Field

Description

Owner

The user who uploaded the dataset

Dataset Name

The original dataset name

Row Count

Total number of rows in the dataset

Customer Identifier

The identifier used when the dataset was registered.

If needed, the Customer Identifier can be updated using the Retry action.

3. Dataset Collaboration

The Dataset Collaboration section shows which connection partners have access to the dataset. This widget provides a quick way to audit who the dataset is shared with and for how long.

This includes:

  • A list of partners with read access

  • When the dataset was shared

  • When the share is set to expire

4. Project Reference Widget

This widget allows you to view which projects the dataset is currently being used in.

Key behavior:

  • Only Active and Locked projects are displayed

  • Projects you do not have access to are hidden

  • Includes a quick link to navigate directly to the project

5. Manage Dataset History

The Dataset History widget allows you to review and manage dataset uploads over time.

When new data is uploaded to an existing Available dataset:

  • The new upload appears here

  • Uploads queue in this section for review and validation

  • You can investigate uploads and take action where needed

6. Dataset Sample

Displays a sample preview of the dataset and its columns.

  • Fields marked as PII will appear as *secure*

  • Useful for validating formatting and column structure at a glance

7. Dataset Lineage

The Dataset Lineage widget allows you to view the original source dataset that your currently available dataset was registered from. This is especially useful when you want to:

  • Review original PII field classifications

  • Investigate data quality reports

💡 The original dataset view contains details such as PII fields classifications, data quality reports, and the ability to view dataset history that are not part of the Available Dataset summary.

8. Non-PII Dataset Fields

This widget provides a view of all non-PII fields contained within the dataset.

You can also:

  • Add or update or add a description for each non-PII field
