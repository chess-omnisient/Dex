Financial Inclusion is a project template that incorporates a large retailer's data for use by a client to match customer data based on both the customer's identity ("Customer") and a specific date ("Date"). You need to have an active subscription to this - please speak to the sales team (sales@omnisient.com)

In general, to determine if model deployment is possible, you would need to consider the following factors:

  1. Data Preparation: Ensure that the data has been adequately prepared for model development. This will be done with the Omnisient Desktop App when uploading a dataset.

  2. This project requires a date column.

  3. Output: You will get your code in a usable manner for SQL Pad and Jupyter Notebook.
