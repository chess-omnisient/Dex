This guide outlines the process of Omnisient’s team creating manual projects on Omnisient, ensuring a seamless experience for users. The Omnisient Team responsible for project creation, will specify project details, enhancing collaboration and insights.

Step-by-Step Instructions:

  1. Inputting Project Details by Omnisient :

    • The system provides an intuitive interface for entering project details.

    • Omnisient users can specify project description, project code, user permissions, and attach reports during manual project creation.

    • Attached reports are readily accessible within the project for easy reference.

  2. Ensuring Backend Readiness:

    • The system checks that all backend objects are created before permitting manual project creation.

    • Necessary tools and functionality are provided for a seamless manual project creation process.

    • The system updates metadata to reflect the successful creation of the manual project.

  3. Viewing and Interacting with Manual Projects:

    • Manually created projects are prominently displayed in the list of the company's projects.

    • Users can effortlessly access each project, utilizing tools like SQL Pad and Jupyter Notebook for effective data interaction.

    • The project page boasts a clean design, featuring a simple interface where project titles are displayed prominently at the top for a user-friendly experience.

Tips and Best Practices:

  • Regularly update project details to maintain accuracy and relevance.

  • Utilize attached reports for a deeper understanding of project insights.
