A Dataset Mapping Schema maps the fields in a data source to the fields set up in Server Connect, and flags which of those fields contain personally identifiable information (PII). Schemas are created when a data upload is set up through Server Connect, and this page is where all of them live so they can be viewed or removed.

Where to find Dataset Schemas

In the Omnisient Platform, go to Datasets → Data Mapping Schemas.

How Dataset Schemas work

Term

Definition

Dataset Schema

A saved configuration that maps the columns in a dataset to the fields you have set up, including which fields are PII and what kind of PII they contain. Schemas are created as part of setting up a data upload through Server Connect.

Notification user

The person who receives an email if a scheduled upload contains invalid data that is flagged or an upload that completes successfully.

PII field

A column flagged as containing personally identifiable information, along with the specific type of PII it holds.

Viewing the schema list

The list shows every Dataset Mapping Schema created for the organization, with its name and the number of fields mapped. From here a schema can be opened to view its detail, or deleted. A confirmation step appears first, so nothing is removed by accident. All users can view and delete schemas.

Opening a schema

Opening a Dataset Mapping Schema shows how each source column has been mapped:

Column

What it shows

Position

The column's position in the source data.

Field name

The name of the mapped field.

PII

Whether the field is flagged as personally identifiable information.

PII field type

The specific type of PII the field contains, if flagged.
